📋 Instrukcje Setup — 3 zadania do wykonania

Postępuj po kolei: Zadanie 1 → Zadanie 2 → Zadanie 3. Potem kliknij ZADANIAukończone na dole strony.

🔑 Zadanie 1: Załóż konto na PyPI

Czas: ~10 min | Po co: żeby opublikować toola do Pythona

  1. Otwórz przeglądarkę i wejdź na: https://pypi.org/account/register/
  2. Wypełnij formularz:
    • Username (Login): wpisz aiconfiggen (jeśli zajety, dodaj myślnik: ai-config-gen)
    • Email: wpisz swój email (np. twój@email.com)
    • Password: wymyśl hasło i zapamiętaj je — potrzebne będzie w Zadaniu 2!
    • Confirm Password: wpisz to samo hasło
  3. Zamień CAPTCHA (zazwyczaj obrazki z kotami/lampami)
  4. Kliknij przycisk Register
  5. Otwórz skrzynkę email — przyjdzie wiadomość z PyPI z linkiem potwierdzającym
  6. Kliknij link w emailu, żeby potwierdzić konto
✅ Gotowe? Wróć tutaj i odznacz Zadanie 1 na dole strony.

🔐 Zadanie 2: Wygeneruj token API dla PyPI

Czas: ~5 min | Po co: żeby tool automatycznie publikował paczkę bez hasła

  1. Wejdź na: https://pypi.org/manage/account/token/
  2. Jeśli Cię zloguje — świetnie. Jeśli nie — kliknij Log in i zaloguj się.
  3. Wypełnij formularz:
    • Name: wpisz ai-config-gen
    • Scope: zaznacz Entire account (to daje dostęp tylko do tego konta PyPI)
  4. Kliknij Add
  5. 🔴 WAŻNE: Wyświetli się token, który wygląda mniej więcej tak: pypi-AgEIc3...dlugaCzcionka...
  6. SKOPIUJ CAŁY TOKEN — wklej go do notatnika (np. Notatnik / Notion / WhatsApp do siebie)
    7. ⚠️ TEN TOKEN WYŚWIETLI SIĘ TYLKO JEDEN RAZ. Jeśli go nie skopiujesz teraz, nie będzie można go odzyskać!
  7. Potem kliknij „ZADANIA ukończone" na dole tej strony i wklej token tam gdzie poproszę
✅ Gotowe? Odznacz Zadanie 2 i wróć.

💰 Zadanie 3: Załóż GitHub Sponsors (opcjonalne)

Czas: ~15 min | Po co: żeby ludzie mogli sponsorować development

To zadanie jest opcjonalne — możesz pominąć, jeśli nie chcesz. Tool i tak będzie działał.

  1. Zaloguj się na: https://github.com
  2. Wejdź na: https://github.com/sponsors/
  3. Kliknij Get started (lub Sign up as a sponsor recipient)
  4. Postępuj zgodnie z instrukcjami na ekranie (GitHub poprosi Cię o dane: kraj, konto bankowe / PayPal)
  5. Gdy skończysz — GitHub wyświetli Ci link typu: https://github.com/sponsors/TWOJ_LOGIN
✅ Gotowe? Odznacz Zadanie 3 i wróć.
