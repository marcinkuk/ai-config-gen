ai-config-gen v0.1.0

Analyze any codebase. Generate optimized AI assistant configs.

Stop writing .claude.md by hand.

Your AI coding assistant needs context. We generate it automatically — from your actual codebase structure, frameworks, conventions, and dependencies.

pip install ai-config-gen
ai-config-gen /path/to/project

How it works

🔍 Analyze

Scans your project: language, frameworks, architecture patterns, package managers, CI/CD, Docker, test frameworks.

📝 Generate

Creates optimized config files for Claude Code, Cursor IDE, and Windsurf — tailored to your codebase.

🚀 Deploy

Drop the configs into your repo. Your AI assistant instantly understands your project.

Output Formats

.claude.mdClaude Code
.cursorrulesCursor IDE
.windsurfrulesWindsurf
