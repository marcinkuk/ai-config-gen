How it works

$ pip install ai-config-gen
$ ai-config-gen ./my-project

🔍 Analyzing ./my-project...

✨ Generated: .claude.md, .cursorrules, .windsurfrules

Features

🔍 Auto-Detection

55+ frameworks: Django, React, Next.js, Laravel, Rails, Spring Boot, and many more.

📦 Zero Dependencies

Pure Python stdlib. No external libraries. Install and run.

🎨 Multiple Formats

Generates configs for Claude Code, Cursor IDE, and Windsurf — in one command.

🐳 Docker Ready

Run as a containerized web API with FastAPI on port 8011.

📝 Smart Analysis

Detects languages, frameworks, CI/CD, Docker, license, and coding conventions.

⚡ VSCode Extension

One-click config generation from the VSCode command palette.
